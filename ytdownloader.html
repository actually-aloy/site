Set a cookies file

If YouTube blocks a download with a "Sign in to confirm you're not a bot" error, a cookies.txt file from a logged-in browser usually fixes it.

1. Install a "Get cookies.txt LOCALLY" extension in Chrome, Firefox, or Edge.
2. Log into youtube.com in that browser.
3. Open any YouTube page, click the extension icon, and export cookies.txt.
4. Click "Select file" below and choose the file you exported.
